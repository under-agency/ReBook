## 📌 О проекте

Салоны красоты, автосервисы и клиники теряют деньги на трёх ключевых утечках:
1. **Каждый пятый записавшийся не приходит** (no-show) — окно сгорает вхолостую.
2. **Ночные и пропущенные заявки уходят конкурентам** — клиент не готов ждать ответа до утра.
3. **«Спящая» база не возвращается** — никто не напоминает записаться вовремя.

**«ReBook»** закрывает все три утечки автоматикой и каждый месяц показывает владельцу заведения в рублях, сколько денег вернула система.

## 🚀 Быстрый запуск демо-бота (Python)

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Настройка переменных окружения
Создайте файл `.env` на основе `.env.example`:
```env
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
GOOGLE_SHEET_ID=id_вашей_google_таблицы
```

Положите ключ сервисного аккаунта Google в корень проекта с именем `google-creds.json` (инструкция в [`docs/demo-setup-guide.md`](docs/demo-setup-guide.md)).

### 3. Запуск
```bash
python3 bot.py
```

## ⚙️ Ключевые параметры

- **Рынок:** РФ, малый сервисный бизнес с записью (салоны, автосервисы, стоматологии/медцентры).
- **Модель:** Разовое внедрение (40–70 тыс. ₽) + абонентка (8–15 тыс. ₽/мес).
- **Цель:** 100 000 ₽/мес recurring доход в течение 3–5 месяцев.
- **Стек:** Python, pyTelegramBotAPI, Google Sheets API, n8n.
