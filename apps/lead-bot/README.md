# Бот заявок

Кнопки лендинга и объявлений ведут в Telegram-бота. Он спрашивает имя, салон,
город и контакт и пересылает заявку в личку команде. Сам бот ничего не хранит.

## Ссылки

`https://t.me/<бот>?start=<метка>` — по метке видно, откуда пришёл человек и
какой тариф смотрел:

| Метка | В заявке |
|---|---|
| `landing` | лендинг |
| `tier_4900` | лендинг, тариф «Старт» 4 900 ₽ |
| `tier_9900` | лендинг, тариф «Полный» 9 900 ₽ |
| `avito_tmn`, `avito_kzn` | Avito и город — его бот уже не спрашивает |

Любая другая метка придёт как есть, без метки — «без метки».

## Запуск

1. Создать бота у @BotFather.
2. `cp .env.example .env` и вписать `LEAD_BOT_TOKEN`.
3. Запустить бота, написать ему `/id` с каждого аккаунта, куда слать заявки,
   вписать chat id через запятую в `LEAD_NOTIFY_CHAT_IDS` и перезапустить.
4. `docker compose up -d --build`

Без Docker: `pip install -r requirements.txt && python bot.py`.
Тесты: `python -m pytest -q`.

## Персональные данные

Имя и контакт — персональные данные. Заявка живёт в памяти, только пока человек
отвечает, потом пересылается и удаляется; в лог пишется только chat id
получателя. Ссылку на политику конфиденциальности задаёт `PRIVACY_URL` — бот
покажет её в первом сообщении.

## Ограничения

- При перезапуске незаконченные заявки теряются.
- Если заявку не удалось доставить ни одному получателю, она теряется, в логе
  будет ошибка.
