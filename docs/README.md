# ReBook

Система автоматизации для бизнесов с записью клиентов: бот записи + каскадные напоминания + реактивация базы. Возвращает деньги, которые бизнес теряет на неявках, медленных ответах и «спящей» базе.

## Одним абзацем

Салоны красоты, автосервисы и стоматологии уже заплатили за привлечение своих клиентов, но теряют их деньги на трёх утечках: каждый пятый записавшийся не приходит, ночные заявки уходят конкурентам, старые клиенты не возвращаются, потому что никто не напомнил. «Антипростой» закрывает все три утечки автоматикой и каждый месяц показывает владельцу в рублях, сколько вернул.

## Ключевые параметры

- **Рынок:** РФ, малый сервисный бизнес с записью (салоны, автосервисы, стоматологии/медцентры)
- **Модель:** разовое внедрение (40–70 тыс. ₽) + абонентка (8–15 тыс. ₽/мес)
- **Цель:** 100 000 ₽/мес recurring в течение 3–5 месяцев
- **Бюджет на старт:** ~2–3 тыс. ₽ (VPS в РФ, домен, баланс SMS)
- **Стек:** свой backend (боты TG + MAX, воркер каскадов, API) + Postgres + собственный веб-кабинет (CRM для владельца + наша админка) на своём домене; LLM — OpenRouter (только FAQ, без ПДн)
- **Команда:** 2 человека — ИБ/инфраструктура/безопасность + разработка (backend, боты, кабинет)

## Дифференциатор

Большинство конкурентов — фрилансеры на конструкторах, продающие «бота как инструмент». Мы продаём **измеримый результат в рублях** (ежемесячный отчёт о возвращённых деньгах) и **надёжность** (данные в РФ, изоляция клиентов, бэкапы, мониторинг — бот не ляжет в субботу вечером).
