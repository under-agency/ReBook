# Дорожная карта (12 недель)

Принцип: **сначала продать, потом строить платформу.** Демо → первый платящий → допиливание на его деньгах → шаблон → масштаб.

## Недели 1–2 — демо и упаковка

**Продукт (брат):**
- [x] Демо-бот: Telegram + n8n + Google Sheets — запись на 3–4 фиктивные услуги, выбор времени
- [ ] Сценарий напоминания с кнопками «Приду / Перенести / Отменить» (для демо — срабатывает через минуту после записи)
- [ ] Один сценарий реактивации («вы были у нас N недель назад…»)

**Инфраструктура и продажи (ИБ-партнёр):**
- [ ] VPS + n8n self-hosted, бэкапы, доступы, healthcheck
- [ ] Самозанятость оформлена, шаблон договора-оферты
- [ ] Оффер-одностраничник с цифрами боли и ссылкой на демо
- [ ] Список 30 салонов/сервисов города и Казани с контактами владельцев

**Выход из этапа:** демо, в которое можно записаться за 30 секунд, и список из 30 контактов.

## Недели 2–5 — первые продажи

- [ ] 10 касаний + 5 фоллоу-апов в неделю по списку
- [ ] Avito-объявление
- [ ] 3–5 разговоров с ЛПР с расчётом потерь по их цифрам
- [ ] Закрыть 1–2 внедрения по спеццене 25–35 тыс. (за видеоотзыв и право публиковать цифры)

Продаём ДО полной готовности: реальное внедрение займёт 1–2 недели — за это время допиливаем под клиента.

**Выход из этапа:** первый платящий клиент.

## Недели 5–8 — первый клиент как полигон

- [ ] Внедрение: интеграция с его расписанием, тексты, обучение админа
- [ ] Сбор всего, что ломается и непонятно, — в бэклог шаблона
- [ ] **Первый месячный отчёт с цифрами** («подтверждено X, возвращено ~N ₽») — главный продающий артефакт
- [ ] Видеоотзыв
- [ ] Параллельно касания не останавливаются: +1–2 клиента

**Выход из этапа:** отчёт с реальными цифрами и отзыв.

## Недели 8–12 — шаблон и масштаб

- [ ] Сценарии первого клиента → шаблонные воркфлоу с конфигом (онбординг ≤ 2 часов техработы)
- [ ] Чек-лист онбординга
- [ ] Цены — полные: 40–70 тыс. внедрение, 8–15 тыс. абонентка
- [ ] Интеграция с YCLIENTS (по первому реальному запросу, не впрок)
- [ ] К концу недели 12: 3–5 клиентов на абонентке + поток внедрений

**Выход из этапа:** суммарный доход ≥ 100 тыс./мес (внедрения + подписка); чистый recurring 100 тыс. — цель месяца 4–5.

## Разделение ролей

| Зона | Брат (AI-автоматизация) | ИБ-партнёр |
|---|---|---|
| Продукт: воркфлоу, интеграции, диалоги, LLM | ✔ основная | ревью |
| Инфраструктура: VPS, бэкапы, мониторинг, изоляция, доступы | — | ✔ основная |
| Продажи: списки, касания, созвоны, договоры | помощь на демо | ✔ основная (опыт переговоров) |
| Отчёты клиентам | генерация данных | упаковка и отправка |

Продажи закреплены за одним человеком — иначе провиснут у обоих.

## Пороговые сигналы (когда менять тактику)

- 4 недели касаний, < 2 платящих → менять сегмент или оффер (например, с салонов на автосервисы), не наращивать спам.
- Внедрения покупают, абонентку нет → переупаковать сопровождение как «страховку + ежемесячный отчёт в рублях».
- Демпинг фрилансеров давит цену → усиливать позиционирование «результат в рублях + надёжность/ИБ», не снижать цену.
- 3+ клиента просят одно и то же → паковать в шаблон/новый модуль (рычаг роста за пределы 100 тыс.).
