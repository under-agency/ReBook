# Руководство по быстрому запуску Демо-бота (Stage 1: Python Setup)

Инструкция по развёртыванию интерактивного Telegram демо-стенда **«ReBook Demo»** на чистом Python за 5 минут.

---

## 1. Регистрация Telegram-бота

1. Откройте в Telegram диалог с **[@BotFather](https://t.me/BotFather)**.
2. Отправьте команду:
   ```text
   /newbot
   ```
3. Укажите название: `ReBook Demo | Запись клиентов`
4. Укажите юзернейм: например, `rebook_demo_bot`.
5. Скопируйте полученный **Bot API Token** (формата `1234567890:ABCdefGHI...`).
6. *(Опционально)* Установите аватарку командой `/setuserpic` и загрузите файл `assets/logo.png`.

---

## 2. Настройка и запуск Python-бота

1. Установите зависимости:
   ```bash
   pip install -r apps/telegram-bot/requirements.txt
   ```
2. Создайте файл `.env` на основе `.env.example`:
   ```env
   TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
   ```
3. Запустите бота:
   ```bash
   python3 apps/telegram-bot/bot.py
   ```

---

## 3. Проверка работы

1. Перейдите по ссылке вашего бота в Telegram и отправьте `/start`.
2. Пройдите сценарий записи:
   - Выберите услугу (например, *Мужская стрижка*)
   - Выберите дату (*Завтра*)
   - Выберите время (*14:00*)
3. Убедитесь, что:
   - Бот мгновенно прислал подтверждающую карточку с номером брони `#RB-XXXX`.
   - В файле `bookings.csv` в корне проекта появилась новая строка записи.
