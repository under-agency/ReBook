# Руководство по быстрому запуску Демо-бота (Stage 1: Python Setup)

Инструкция по развёртыванию интерактивного Telegram демо-стенда **«ReBook Demo»** на чистом Python за 5 минут.

---

## 1. Регистрация Telegram-бота

1. Откройте в Telegram диалог с **[@BotFather](https://t.me/BotFather)**.
2. Отправьте команду:
   ```text
   /newbot
   ```
3. Укажите название: `ReBook Demo | Запись клиентов`
4. Укажите юзернейм: например, `rebook_demo_bot`.
5. Скопируйте полученный **Bot API Token** (формата `1234567890:ABCdefGHI...`).
6. *(Опционально)* Установите аватарку командой `/setuserpic` и загрузите файл `assets/logo.png`.

---

## 2. Подготовка Google Таблицы

1. Создайте новую таблицу в Google Sheets (например, `ReBook - Демо расписание`).
2. Назовите первый лист **`Записи`**.
3. Добавьте в первую строку заголовки (или используйте файл [`templates/demo-bookings-template.csv`](../templates/demo-bookings-template.csv)):
   | A | B | C | D | E | F | G | H | I | J |
   |---|---|---|---|---|---|---|---|---|---|
   | **ID Брони** | **Дата создания** | **Клиент ID** | **Имя клиента** | **Telegram** | **Услуга** | **Стоимость** | **Дата визита** | **Время** | **Статус** |

4. Скопируйте **ID таблицы** из URL адресной строки:
   `https://docs.google.com/spreadsheets/d/`**`1a2B3c4D_YOUR_SHEET_ID`**`/edit`
5. В Google Cloud Console создайте Service Account, скачайте ключ `google-creds.json` в корень проекта и предоставьте доступ к таблице на email сервисного аккаунта.

---

## 3. Настройка и запуск Python-бота

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Создайте файл `.env` на основе `.env.example`:
   ```env
   TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
   GOOGLE_SHEET_ID=id_вашей_google_таблицы
   ```
3. Запустите бота:
   ```bash
   python3 apps/telegram-bot/bot.py
   ```

---

## 4. Проверка работы

1. Перейдите по ссылке вашего бота в Telegram и отправьте `/start`.
2. Пройдите сценарий записи:
   - Выберите услугу (например, *Мужская стрижка*)
   - Выберите дату (*Завтра*)
   - Выберите время (*14:00*)
3. Убедитесь, что:
   - Бот мгновенно прислал подтверждающую карточку с номером брони `#RB-XXXX`.
   - В Google Таблице и в локальном файле `bookings.csv` появилась новая строка записи.
