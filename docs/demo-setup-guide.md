# Руководство по быстрому запуску Демо-бота (Stage 1: KISS Setup)

Инструкция по развёртыванию интерактивного Telegram демо-стенда **«ReBook Demo»** за 5 минут.

---

## 1. Регистрация Telegram-бота (2 минуты)

1. Откройте в Telegram диалог с **[@BotFather](https://t.me/BotFather)**.
2. Отправьте команду:
   ```text
   /newbot
   ```
3. Укажите название: `ReBook Demo | Запись клиентов`
4. Укажите юзернейм: например, `rebook_demo_bot` (или `rebook_вашгород_bot`).
5. Скопируйте полученный **Bot API Token** (формата `1234567890:ABCdefGHI...`).
6. *(Опционально)* Оформите бота в BotFather:
   - `/setdescription` — *«Демо-стенд системы ReBook: онлайн-запись за 30 секунд, каскадные напоминания, реактивация базы.»*
   - `/setabouttext` — *«Автоматизация записи и возврата клиентов для сферы услуг.»*

---

## 2. Подготовка Google Таблицы (1 минута)

1. Создайте новую таблицу в Google Sheets (например, с названием `ReBook - Демо расписание`).
2. Переименуйте первый лист в **`Записи`**.
3. Добавьте в первую строку заголовки (или импортируйте файл [`templates/demo-bookings-template.csv`](../templates/demo-bookings-template.csv)):
   | A | B | C | D | E | F | G | H | I | J |
   |---|---|---|---|---|---|---|---|---|---|
   | **ID Брони** | **Дата создания** | **Клиент ID** | **Имя клиента** | **Telegram** | **Услуга** | **Стоимость** | **Дата визита** | **Время** | **Статус** |

4. Скопируйте **ID таблицы** из URL адресной строки браузера:
   `https://docs.google.com/spreadsheets/d/`**`1a2B3c4D_YOUR_SHEET_ID`**`/edit`

---

## 3. Импорт воркфлоу в n8n (2 минуты)

1. Откройте ваш инстанс **n8n**.
2. В правом верхнем углу нажмите **`+ Add Workflow`** → меню три точки `...` → **`Import from File`**.
3. Выберите файл [`workflows/demo-booking.json`](../workflows/demo-booking.json).
4. Настройте Credentials (креденшелы):
   - **Telegram Trigger & Telegram Nodes**: выберите или создайте Telegram API Credentials с токеном из Шага 1.
   - **Save to Google Sheets**: выберите Google Sheets OAuth2 / Service Account и укажите ваш `Document ID` из Шага 2.
5. Нажмите **`Save`** и переведите переключатель воркфлоу в статус **`Active`**.

---

## 4. Проверка и демонстрация

1. Перейдите по ссылке вашего бота в Telegram и отправьте `/start`.
2. Пройдите сценарий:
   - Выберите услугу (например, *«✂️ Мужская стрижка»*)
   - Выберите дату (*«Завтра»*)
   - Выберите время (*«14:00»*)
3. Убедитесь, что:
   - Бот мгновенно прислал подтверждающую карточку с номером брони.
   - В Google Таблице появилась новая строка с данными вашей записи.
