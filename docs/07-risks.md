# Риски и обходные пути

## Технические

| Риск | Вероятность | Митигация |
|---|---|---|
| WhatsApp: неофициальные библиотеки банят, официальный API дорог | Высокая | Каскад строим на Telegram + MAX + SMS. WhatsApp — только официальный API и только если клиент платит за него отдельно |
| MAX: молодая платформа — правила публикации/верификации и API могут меняться | Средняя | MAX — этап 5, не блокер запуска; каскад работает на TG + SMS без него. Требования верификации перепроверяем на dev.max.ru перед этапом |
| OpenRouter: запросы уходят на зарубежную инфраструктуру | — | ПДн в промпт не попадают технически (фикс. поля + текст вопроса); при появлении требований клиента — переключение провайдера в llm.py, одна точка |
| Свой код вместо конструктора: дольше первый результат, багов больше на старте | Средняя | Этапность (ядро → кабинет), тесты на каскад и изоляцию тенантов, демо-салон как постоянный прогон |
| YCLIENTS API недоступен на тарифе клиента | Средняя | Проверять тариф ДО обещания интеграции; фолбэк — наш кабинет как их единственная система |
| Падение VPS/вебхуков → бот молчит, клиент злится | Средняя | Healthcheck + алерты в наш Telegram, бэкапы, регламент восстановления. Надёжность — часть оффера, значит и часть работы |
| LLM отвечает ерунду на свободный вопрос | Средняя | LLM только для FAQ по базе знаний; неуверенный ответ → передача админу. Запись и напоминания — детерминированные кнопки |
| Telegram не у всех клиентов салона | Низкая-средняя | SMS-догон закрывает недостижимых; проникновение Telegram в РФ высокое |

## Рыночные

| Риск | Митигация |
|---|---|
| Демпинг фрилансеров («бот за 5 тыс.») | Не конкурировать по цене инструмента. Продаём результат в рублях + отчёт + надёжность. Их боты протухают за 3–6 мес — часть наших клиентов придёт после них |
| YCLIENTS/CRM добавят похожие функции «из коробки» | Мы — слой кастомизации и сопровождения поверх любой системы; коробка не делает тексты, циклы услуг и отчёт под конкретный салон. Держать руку на пульсе их релизов |
| Сезонность у ЦА (салоны проседают летом) | Диверсификация ниш: салоны + автосервисы (у них пики противоположные — шиномонтаж, подготовка к зиме) |
| Клиент уходит после внедрения, не берёт абонентку | Отчёт с рублями каждый месяц; предупреждение о «протухании»; правки текстов только в рамках абонентки |

## Операционные (главные для side-проекта)

| Риск | Митигация |
|---|---|
| Первые клиенты съедают больше времени, чем ожидалось | Закладывать возню в цену внедрения, не в абонентку. Не брать > 2 внедрений параллельно на старте |
| Основная работа/учёба съедает время → проект стоит | Фиксированные слоты в неделю на проект + норма касаний (10/нед) как минимальный пульс. Меньше нормы 2 недели подряд — честный разговор о приоритетах |
| Конфликты ролей между партнёрами | Зоны закреплены письменно (см. roadmap); решения по деньгам — только вдвоём; договорённость о долях — до первого рубля |
| «Вечный фриланс» вместо продукта: каждый клиент — кастом | Правило: 3+ одинаковых запроса → в шаблон. Онбординг > 2 часов техработы → разбираем, что нешаблонно |

## Регуляторные

| Риск | Митигация |
|---|---|
| Персональные данные клиентов салонов проходят через нас | Минимизация: храним только имя, контакт, историю визитов. Данные в РФ, изоляция, ПДн в LLM не отправляем. Формально оператор ПДн — сам салон; наша роль — обработка по поручению (пункт в договоре) |
| Рассылки = реклама → согласие на получение | Напоминания о записи — сервисные сообщения (ок). Реактивация — по базе, давшей контакт добровольно, всегда с возможностью отписки кнопкой. Шаблон согласия — салону в комплект |
| Маркировка звонков юрлиц (с 2026) | Голосовые обзвоны в продукт не включаем — риск неактуален, пока не выйдем в голос |
| Лимит НПД 2,4 млн ₽/год | При приближении — ИП на УСН (заложено в бизнес-модели) |

## Чего осознанно НЕ боимся

- «Рынок ботов перенасыщен» — перенасыщен рынок *инструментов*; рынок *результата с отчётом в рублях* для сервисного МСБ фрагментирован и открыт.
- «Придёт большой игрок» — большим неинтересен чек 10 тыс./мес с ручным онбордингом; наша защита — локальность, сервис и скорость.
